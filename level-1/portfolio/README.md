## 🚀 Project Overview

This is my personal developer portfolio, designed as a highly interactive, retro-style terminal interface. Instead of a standard scrolling website, visitors are greeted with a boot sequence and can navigate through my projects, skills, and experience using a command-line interface feel.

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (Vanilla)
- **Deployment:** Vercel

## ✨ Features

- 🖥️ **Terminal UI:** An immersive, command-line style interface.
- ⌨️ **Interactive Commands:** Users can type commands to explore different sections (e.g., `about`, `projects`, `skills`, `contact`).
- 🟢 **Boot Sequence:** A custom retro boot-up animation that runs on load.
- 📱 **Responsive Design:** Works flawlessly on both desktop and mobile devices.

## ⚙️ Setup Instructions

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Sainitesh10/portfolio.git
   cd portfolio
   ```

2. **Run Locally:**
   Since this is a vanilla HTML/CSS/JS project, you don't need any complex build tools. Simply open `index.html` in your web browser:
   - On Windows: Double-click `index.html`
   - Alternatively, you can use a tool like Live Server in VS Code.
