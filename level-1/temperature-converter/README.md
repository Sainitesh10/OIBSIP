# Temperature Converter — Level 1 Task 3

A retro-futuristic, interactive temperature converter supporting real-time mathematical translations across Celsius, Fahrenheit, and Kelvin scales.

## 🚀 Features

- **Ambient Background Animations:** Customized floating math formulas and blur-gradient orbs.
- **Bidirectional Conversion:** Translates entered temperature values simultaneously across all three scales.
- **Visual Card Focus:** Interactive card components that transform styling when selected as the active input.
- **Formula Breakdown:** Detailed step-by-step mathematical explanation of the conversion formula.
- **Input Validation:** Real-time checking to prevent non-numeric values from breaking calculation logs.

## 🛠️ Tech Stack

- **Structure:** HTML5
- **Style:** Vanilla CSS3
- **Logic:** Vanilla JavaScript

## 🖥️ How to Run

Open `index.html` in your web browser. Type a value in the input box, select the input scale, and click **Convert** (or press the **Enter** key).
