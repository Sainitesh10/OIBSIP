# FlowSync Landing Page — Level 1 Task 1

A premium, modern, and fully responsive product landing page for a fictional productivity application named **FlowSync**.

## 🚀 Features

- **Syne & DM Sans Typography:** Curated visual aesthetics using modern Google Fonts.
- **Dynamic CSS Animations:** Smooth micro-animations, pulsating badges, and floating dashboard cards.
- **Pricing Section:** Interactive three-tiered pricing grid with a highlighted "Popular" option.
- **Client Testimonials:** Dynamic carousel of client reviews featuring customized avatars.
- **Navigation Menu:** Sticky blur-backdrop navigation bar with responsive CTAs.

## 🛠️ Tech Stack

- **Structure:** HTML5
- **Style:** Vanilla CSS3 (Custom Variables, Flexbox, CSS Grid)

## 🖥️ How to Run

Simply double-click the `index.html` file to open the landing page in any web browser.
