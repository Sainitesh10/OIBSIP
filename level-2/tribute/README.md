# Hardik Pandya Tribute Page — Level 2 Task 2

A structured timeline and media-rich tribute page honoring Hardik Pandya, "The Comeback King" of Indian cricket.

## 🚀 Features

- **Responsive Grid Layout:** Layout grid showcasing timeline events, biography details, and career stats.
- **Chapter-Based Timeline:** Chronological narration of his humble beginnings, rise, career-threatening injuries, public trolling, and ultimate redemption in the T20 World Cups.
- **Embedded Career Statistics:** Highlight cards displaying historical achievements (IPL matches, World Cups, wickets, and runs).
- **Stylized Quote Card:** Prominent blockquote focusing on resilience and self-improvement.

## 🛠️ Tech Stack

- **Structure:** HTML5
- **Style:** Vanilla CSS3
- **Fonts:** Bebas Neue & Poppins

## 🖥️ How to Run

Simply open `index.html` in your web browser to scroll through his journey.
