# Cyberpunk Calculator (CALC//SYS) — Level 2 Task 1

A retro-futuristic, high-fidelity grid calculator built with a sleek terminal-aesthetic interface.

## 🚀 Features

- **Cyberpunk UI Theme:** Scanline overlays, neon glow backdrops, and active status animations.
- **Math Operation Chaining:** Chain operations seamlessly (e.g., `A + B * C`).
- **Safety Handling:** Division-by-zero error handling displaying `ERR:DIV0`.
- **Keyboard Shortcuts:** Support for numeric keys, standard operators (`+`, `-`, `*`, `/`), `Enter` (equal), `Backspace`, and `Escape` (clear).
- **Interactive Feedback:** Ripple click animations on all grid buttons.

## 🛠️ Tech Stack

- **Structure:** HTML5
- **Style:** Vanilla CSS3
- **Logic:** Vanilla JavaScript

## 🖥️ How to Run

Open `index.html` in your web browser. Input calculations using either the screen buttons or your physical keyboard.
