# TaskFlow To-Do Web App — Level 2 Task 3

An interactive, responsive task management application with a glassmorphic look.

## 🚀 Features

- **Live Date & Time Clock:** Displaying real-time clocks and dates.
- **Progress Tracking:** Dynamic completion percentage calculations and visual progress bar fills.
- **Distinct Status Sections:** Separate lists for pending tasks and completed tasks.
- **Full CRUD Support:** Add tasks, edit existing task contents, mark tasks as complete/incomplete, and delete tasks.
- **Bulk Actions:** Quick button to clear all completed tasks at once.
- **Toast Notifications:** Smooth toast pop-ups giving real-time feedback on actions.

## 🛠️ Tech Stack

- **Structure:** HTML5
- **Style:** Vanilla CSS3
- **Logic:** Vanilla JavaScript

## 🖥️ How to Run

Open `index.html` in your web browser. Write a task in the input field, click **Add**, and organize your day.
