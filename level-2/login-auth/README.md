# AuthFlow Login Authentication System — Level 2 Task 4

A secure, simulated client-side authentication application supporting full registration, login, verification, and dashboard sessions.

## 🚀 Features

- **Multi-Screen Navigation:** Clean, seamless switching between Login, Account Creation, OTP Verification, Password Recovery, and Dashboard view.
- **Input Validation:** Real-time form checks preventing invalid formats (email checks, name length constraints).
- **Password Strength Checker:** Live feedback scoring password complexity (Weak, Fair, Good, Strong).
- **OTP Code Logic:** 6-digit passcode inputs automatically shifting focus to the next field. Includes a demo resend-timer countdown.
- **Dashboard Portal:** Authenticated session simulation displaying profile metrics, activity cards, and security logs.
- **Toast Notifications:** UI toast pop-ups signaling successes or error events.

## 🛠️ Tech Stack

- **Structure:** HTML5
- **Style:** Vanilla CSS3
- **Logic:** Vanilla JavaScript

## 🖥️ How to Run

Open `index.html` in your web browser. Create an account, fill in form details, and test the dashboard portal.
